# GitHub Blog

Blog desenvolvido com React e TypeScript que consome a API do GitHub, exibindo issues de um repositório como posts, com funcionalidade de busca. Desenvolvido durante o curso Ignite da Rocketseat.

## Tecnologias

- [React](https://react.dev/) — biblioteca para construção de interfaces
- [TypeScript](https://www.typescriptlang.org/) — tipagem estática
- [Vite](https://vitejs.dev/) — bundler e servidor de desenvolvimento
